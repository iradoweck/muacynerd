# LIBRIVAS - Agent Rules

These rules dictate the behavior of the AI agent for the LIBRIVAS project.

## Language Standards

1. **Chat & Artifacts:** MUST be written in **Portuguese**.
2. **Code, Commits, PRs, Documentation & Templates:** MUST be written in **English**.
3. **Website Content / UI Copy:** MUST be written in **European Portuguese** (Português de Portugal).

## Execution Constraints

1. **Commits:** DO NOT create any Git commits without explicit user consent.
2. **Subagents:** DO NOT spawn or invoke any subagents without explicit user consent.

## Git Strategy

1. **Branches:**
   - `main`: Production branch. ONLY receives Pull Requests. Currently empty.
   - `devlab`: Active development branch. All initial work and development happens here.
2. **Workflow:** Work must start on `devlab` while keeping `main` clean and connected.
